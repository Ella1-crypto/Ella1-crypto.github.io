    03 · DRAFT

    소재를 적으면 초안 다섯 개.

    소재를 한 줄에 하나씩 적고 누르면 루틴의 규칙대로 글 초안을 쓰고, 바로 아래 검수기로 넘깁니다. 소재 찾기와 스레드 게시는 여기서 하지 않습니다.

    1. 소재를 적는다한 줄에 하나, 상품명 | 확인한 사실 형식으로 최대 5개. 옆에 적지 않은 가격·효과·배송은 글에 들어가지 않습니다.
    2. 키를 넣는다무료로 쓰려면 aistudio.google.com → Get API key 로 받은 AIza… 키를 넣습니다(구글 로그인만, 카드 불필요). 폰에서는 아래 이 기기에 키 저장을 켜 두면 다음부터 다시 넣지 않아도 됩니다. Anthropic 키(sk-ant-…)를 넣으면 그쪽으로 갑니다(유료).
    3. 초안 만들기를 누른다수십 초 걸립니다. 다 되면 글 5개가 아래 04 · CHECKER 칸에 ---로 구분되어 들어갑니다.
    4. 오늘 단계에 맞게 고친다맨 위 TODAY 카드의 단계를 봅니다. 링크 없는 기간이면 마지막 줄을 질문형으로, 링크 기간이면 링크 댓글에로 끝냅니다.
    5. 검수한다❌가 없을 때까지 고칩니다. 첫 줄 상품명, 직접 써 본 표현, 본문 주소, 5줄 초과가 주로 걸립니다.
    6. 사람이 올린다게시는 직접 합니다. 02 · TIMETABLE에서 메인 계정과 30분 이상 떨어졌는지 먼저 확인하고, 링크와 고지문은 첫 댓글에 답니다.

    • 키는 기본적으로 저장하지 않습니다이 탭의 메모리에만 있고 새로 고치면 사라집니다. "이 기기에 키 저장"을 켠 경우에만 그 기기의 브라우저 저장소에 남고, 끄면 바로 지워집니다. 키는 고른 모델의 API 로만 전송됩니다.
    • 사용량은 내 키로 잡힙니다Google AI Studio 키는 무료 한도 안에서 쓰고, 한도를 넘으면 "요청 한도를 넘었습니다"가 뜹니다. Anthropic 키는 누를 때마다 요금이 나갑니다. 응답까지 수십 초 걸릴 수 있습니다.
